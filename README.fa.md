# OptiPixel 🖼️⚡ (راهنمای فارسی)

**اپتی‌پیکسل (OptiPixel)** یک نرم‌افزار دسکتاپ و ابزار وب قدرتمند، پرسرعت و متن‌باز برای بهینه‌سازی گروهی تصاویر، تبدیل فرمت‌ها و ممیزی سئو و سرعت وب‌سایت است که با پایتون (PySide6) و موتور قدرتمند ImageMagick 7 طراحی شده است.

زبان‌ها: [English](README.md) | [فارسی](README.fa.md)

---

## 🌟 قابلیت‌های اصلی

- **⚡ بهینه‌سازی گروهی تصاویر**: فشرده‌سازی با کیفیت عالی برای فرمت‌های WebP, AVIF, JPEG, PNG, TIFF و BMP.
- **🎯 فیلتر آستانه حجم (Threshold)**: صرف‌نظر خودکار از تصاویری که کوچکتر از حد تعیین شده (مثلاً ۴۰۰ کیلوبایت) هستند.
- **🛡️ محافظت از فایل اصلی**: عدم جایگزینی در صورتی که فایل خروجی حجیم‌تر از فایل اصلی گردد.
- **📐 تغییر ابعاد هوشمند**: محدود کردن حداکثر عرض و ارتفاع با حفظ نسبت ابعاد.
- **🏷️ پاکسازی متاداده**: حذف اطلاعات اضافی EXIF برای کاهش حجم و افزایش حریم خصوصی.
- **🔍 آنالیز و ممیزی سئو تصاویر (Audit)**: اسکن فقط-خواندنی پوشه‌های وب‌سایت جهت شناسایی تصاویر کندکننده صفحات.
- **💼 استراتژی‌های متنوع خروجی**: ذخیره در پوشه مجزا، جایگزینی همراه با نسخه پشتیبان یا ذخیره در کنار فایل اصلی.
- **❤️ پشتیبانی از حمایت مالی (Donation)**: امکان حامی شدن و حمایت از پروژه از طریق کیف پول رمزارز شبکه TON.

## 📦 نحوه ساخت فایل اجرایی (Build) و انتشار انتشارها (Releases)

### ۱. پیش‌نیازها
- پایتون ۳.۱۰ یا بالاتر
- نرم‌افزار ImageMagick نسخه ۷ (افزوده شده به PATH سیستم)
- نرم‌افزار Inno Setup 6 (برای ساخت فایل نصب‌کننده Windows)

### ۲. اجرای اسکریپت ساخت (Windows)
در محیط PowerShell اسکریپت زیر را اجرا کنید:
```powershell
.\build.ps1
```
این اسکریپت سورس پایتون را با PyInstaller به فایل اجرایی تبدیل کرده و فایل نصب‌کننده `OptiPixel-Installer.exe` را می‌سازد.

### ۳. انتشار نسخه جدید در گیت‌هاب (GitHub Release)
۱. ابتدا نسخه جدید را تگ بزنید:
   ```bash
   git tag -a v0.1.0 -m "Release v0.1.0"
   git push origin v0.1.0
   ```
۲. به لینک انتشار نسخه جدید بروید:
   [https://github.com/h08831n/OptiPixel/releases/new](https://github.com/h08831n/OptiPixel/releases/new)
۳. تگ `v0.1.0` را انتخاب کرده و عنوان و توضیحات تغییرات را وارد کنید.
۴. فایل‌های خروجی `OptiPixel-Installer.exe` را آپلود نموده و روی Publish Release کلیک کنید.
